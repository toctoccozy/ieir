<td align="left" valign="top" width="534"><b><font size="+1">慈愛にみち、優しさの中に気品ただようお地蔵さま。<br/>

身近におけば、日々の安らぎが、手にとって抱けば、心なごむひとときが…<br/>

仏教美術の伝統をふまえ、心を込め技のすべてを傾けて今ここに完成された珠玉のオリジナル地蔵像。</font></b><br/>
<br/>
<font size="2">■</font><font size="2">友沢正彦作<br/>

■作家の署名入り<br/>
<br/>
<br/>

無限のやさしさと慈しみの心で、すべての人々をつつみ込み、どんな願いをもききとどけてくださるお地蔵さま。古来もっとも身近な仏として日本人に親しまれ、尊ばれてきた地蔵菩薩が、現代彫刻界の第一線で活躍する著名な作家により、峻厳な気品と素朴な温かさとをかねそなえた比類ない芸術作品に完成されました。合掌地蔵「祈り」は、仏教美術に精通した名高い彫刻家、友沢正彦氏が、現代人のために心を込め、もてる技のすべてを注いで創りあげたオリジナル・ブロンズ彫刻です。作者の友沢正彦氏は、現代彫刻界の中枢をになう著名な彫刻家です。具象彫刻界の大家として有名な故寺畑助之丞氏に師事し、厳しい研鑽を積んだ友沢氏は、昭和三十七年に新構造社展会員となり、同展大賞をはじめ数々の賞を受賞。代表作には、川崎大師山門の四天王像や日本の童などがあり、さらに、観音像、如意輪観音像など仏教美術の世界で注目される大作、名作も手がけています。<br/>
<br/>
<b>暮らしに潤いをもたらす珠玉の美術品<br/>

そっと抱けば、心なごむひとときが</b><br/>
<br/>

合掌地蔵「祈り」は、友沢芸術の真髄が結晶した瑞々しい傑作です。静かに目をとじ、あらゆるものの幸せを願うかのように一心に手を合わせて祈りつづける姿。仏教美術の伝統をふまえながらも、自由でのびやかな表現により、幼子の純真な美しさと気品、さらに、人間味ゆたかな趣さえただよわせるオリジナル彫刻となりました。本作品は、身近におかれて、日々、目にされるだけで、暮らしにあたたかな潤いが生まれる美術品です。また、地蔵像をお手にとって、そっと抱き、あるいは慈しむように撫でることにより、ずっしりとした重量感と、掌になじむ優しい温もりを感じるとともに、いっそう心が安らかになるのをお感じいただけます。「祈り」は、伝統の技を駆使して、一体ずつ丁寧にブロンズ鋳造されます。友沢氏のオリジナル原型の素晴らしさが、美術工芸の匠による熟練の手技で、あますところなくブロンズ像にうつしとられています。鋳造されたブロンズ像には、伝統のおはぐろ技法で美しい古色が加えられ作品の格調をいやがうえにも高めます。作品には、地蔵菩薩について書き下ろされた解説書が付属します。</font><br/>
