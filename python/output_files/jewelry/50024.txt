<p class="intro">可憐に咲き誇る桜の花をとぎれることなく連ねた<br>
かつてないエレガントな宝飾エタニティリングが誕生。<br>
幾つもの花びらをかたどる<br>
華やかな18金ピンクゴールド仕上げの輝きに<br>
12石以上ものダイヤモンドを贅沢にちりばめた<br>
このうえなくゴージャスなデザイン。<br/>
日本の美しい桜の情景に魅せられて<br/>
フランスの著名デザイナーがおくる輝きの賛辞。</br></br></br></br></br></p>

<p>“桜”──それは、艶やかに色づく美しさと凛とした気高さで、人々を惹きつけてやまない薄紅の花。舞い散る刹那にも儚い余韻を残し、古くより日本人が格別な思いを寄せてきたその麗しき桜花が、このたび、永遠にきらめく華麗なジュエリーにその姿をうつしました。<br/>
あたたかな春の訪れを告げる美しい日本の景色に魅せられて、フランスの著名デザイナー、カティ・ドレー氏がおくる＜桜エタニティ＞。可憐に咲き誇る桜花のモチーフをとぎれることなく全周に連ねた、エレガントな宝飾エタニティリングです。</p>
<h2>贅沢な18金ピンクゴールドの輝きに、ダイヤモンドのきらめき<br/>
花びらの一片一片まで細やかに表現した、精緻な造形美</h2>
<p><img align="right" alt="" height="204" src="/image/goods/5002400_03.jpg" style="margin: 0 0 12px 12px;" width="150"/>しあわせな華やぎがどこまでも続くように、きらめく桜花が永遠の環をつむぐエタニティリング。やさしい薄紅色を帯びた桜の花は、豪華な18金ピンクゴールド仕上げスターリング・シルバー（.925銀）製。立体的にかたどられた幾つもの花びらに、12石以上ものダイヤモンドが贅沢にあしらわれました。ひとつひとつの花びらを重ねるように、緻密に表現された細工の美しさ。上品な光沢をたたえるつや有りとマットなつや消し、それぞれの輝きが絶妙なコントラストを奏でる洗練のデザインは、ニナリッチをはじめ、世界的な名門ブランドでも活躍してきたカティ・ドレー氏ならでこそ。身につけるたび、完成された造形美とラグジュアリーな輝きで、華麗に指元を彩ることでしょう。</p>

<h3>カティ・ドレー</h3>
<div><img align="right" alt="" height="153" src="/image/goods/5002400_05.jpg" style="margin: 0 0 12px 12px;" width="125"/>フランスの著名デザイナー。かつてはニナリッチのコレクションのモデルとして活躍し、「Elle」や「Marie-France」といった世界的に有名なファッション雑誌の表紙も飾った。その後パリのファッション・インスティテュートでデザインを学び、ニナリッチやクレージュなどの世界的有名ブランドのデザイナーとして活躍。現在パリにアトリエを構え、マチュー・カソビッツ監督の「La Haine（憎しみ）」（カンヌ映画祭最優秀監督賞受賞作品）をはじめ数々のフランス映画の衣装デザインも手がけている。</div>
